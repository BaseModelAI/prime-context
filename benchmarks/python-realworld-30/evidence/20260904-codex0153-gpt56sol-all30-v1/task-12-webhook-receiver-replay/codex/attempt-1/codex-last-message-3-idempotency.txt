Implemented durable `X-Event-ID` idempotency.

- First valid external ID returns `202` with a new local ID.
- Reposts return `200` with the original local ID.
- Duplicate requests cannot modify payload, delivery status, retry state, or counters.
- Headerless requests remain non-idempotent.
- Existing databases migrate automatically.
- A SQLite unique index prevents duplicate rows under concurrent requests.

Verified normal, headerless, malformed, migration, and concurrent duplicate scenarios.
